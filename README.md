# Файна поляна — сайт ягідного кооперативу

Корпоративний B2B-сайт сільськогосподарського кооперативу «Файна поляна» (с. Городище, Тернопільщина):
презентує кооператив іноземним і українським партнерам, а місцевим виробникам показує ціни приймання ягід.

Самостійна робота з курсу «Технології веб розробки та дизайну» (ПП-26). **Демо-версія:** частина даних
демонстраційна — перелік у `Демо-дані.md` (папка проєкту на диску).

## Сторінки

| Файл | Призначення |
|---|---|
| `index.html` | Головна: про кооператив, у цифрах, кооперативна модель, принцип роботи, асортимент, якість, карта, ринок, новини |
| `partners.html` | Партнерам: з ким працюємо, переваги, модель, керівництво, структура, географія, цінності |
| `plans.html` | Наші плани: таймлайн, хаб «Городище 2028», зберігання, енергонезалежність, економічні цілі, стратегія |
| `intake.html` | Приймання ягід: ціни, **калькулятор заробітку**, кроки, вимоги, пункти приймання, членство, FAQ |
| `contacts.html` | Співпраця: етапи, формати (зокрема інвестиції, гранти, тендери), **форма заявки з двома режимами — покупець / інвестор** (`?type=investor`), контакти, як доїхати |

## Стек

HTML5 · Tailwind CSS 3.4 (зібраний, `css/tailwind.css`) · Vanilla JS (IIFE, без глобальних змінних) ·
AOS 2.3.4 і GLightbox 3.3.1 з jsDelivr (з `integrity`) · Google Fonts (Roboto, Roboto Slab, Marck Script) · Vercel Web Analytics.

## Інтерактивність

- `js/calculator.js` — калькулятор заробітку: `fetch('data/data.json')` → таблиця цін, таблиця пунктів, список ягід;
  розрахунок «зараз» / «у кінці сезону (+50 % для членів)» / вигода; валідація ваги (RegExp, межі 1–500 кг), обробка помилки завантаження.
- `js/contact-form.js` — форма заявки партнера: RegExp для назви компанії, імені, email, телефону (E.164) і обсягу,
  маска міжнародного телефону, honeypot проти ботів, модальне вікно `<dialog>`. Дані нікуди не надсилаються.
- `js/i18n.js` — перемикач UA/EN: українська в HTML, англійська — `i18n/en.json` (fetch за потреби), вибір у `localStorage`.
- `js/main.js` — мобільне меню («шторка»), ініціалізація AOS і GLightbox (з урахуванням `prefers-reduced-motion`).

## Дані

- `data/data.json` — ціни ягід, надбавки за довідку про дохід, ставка премії, ліміти ваги, пункти приймання.
- `i18n/en.json` — англійський переклад (генерується).

## Карта

Карта Західної України на головній, «Прийманні ягід» і «Контактах» — inline SVG, яку генерує `tools/build-pages.py`.
Межі областей: Natural Earth admin-1 (public domain) через пакет `datamaps` 0.5.9 (MIT) → `tools/west-ukraine.geojson`, `tools/ukraine-inset.geojson`.

## Як змінювати тексти

Тексти сторінок і їхні переклади записані один раз у `tools/build-pages.py` (UA + EN поруч), скрипт генерує HTML і `i18n/en.json`:

```bash
python3 tools/build-pages.py   # сторінки + переклад
npm run build:css              # Tailwind → css/tailwind.css
```

## Збірка й перевірки

```bash
npm ci
npm run build:css   # Tailwind 3.4.17 → css/tailwind.css (комітиться)
npm run lint:html   # html-validate
npm run lhci        # Lighthouse CI: A11y / Best Practices / SEO ≥ 90, Performance ≥ 85 (попередження)
npm run check       # усе разом — те саме робить GitHub Actions
```

Продакшн: https://faina-polyana.vercel.app — оновлюється лише через GitHub Actions (`.github/workflows/deploy.yml`)
після зелених перевірок. Потрібні секрети репозиторію: `VERCEL_TOKEN`, `VERCEL_ORG_ID`, `VERCEL_PROJECT_ID`.

## Запуск локально

VS Code → Live Server → `index.html` (потрібен саме сервер: `fetch` не працює з `file://`).
